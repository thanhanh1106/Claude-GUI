Bảng "Thay đổi" theo repo + cây git

Claude sửa tệp thuộc repo nào thì repo đó tự hiện thành một tab trong bảng Thay đổi (chưa có tab thì thêm, có rồi thì cập nhật số). Trong tab: nhánh, stage thủ công bằng ô chọn, commit tay, hoặc giao Claude commit theo luật; bên dưới là cây git. Tệp Claude vừa sửa có nhãn ✳ để phân biệt với tệp bạn tự sửa.

Giả lập
Hiện tại trong app: tab "Phiên này" liệt kê mọi tệp Claude sửa trong phiên (cả tệp nháp ngoài repo), tab "Git" chỉ có khi thư mục của phiên là repo — nên phiên chạy ở dist mà sửa tệp ở ClaudeGUI thì không thấy gì. Bản mới: dò repo theo từng tệp được sửa.
